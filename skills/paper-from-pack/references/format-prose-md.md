# prose-md (practitioner article, post, tutorial)

Output: `DRAFT.md`. Template: `assets/templates/prose-md.md`.
Limits: words (for example 800-1,000, 2,000-4,000) from `venue.json`; `check_limits.py --text DRAFT.md` (code blocks excluded and reported). If the venue is exclusive or editor-reviewed, state that in SUBMIT.md.
Shape: a lead that states the situation with one sourced fact; a clear claim in the first 150 words; short sections; commands and code only from the pack's data (never invented output); a "what I did not measure" section; numbers with n; the approved bio.
Tutorials: every command and its output must exist in the pack or its results files. If it does not, write `TO VERIFY: run this and paste the real output` and list it in OPEN.md as something the author must re-run.
Pitch-first outlets: if the pack says to pitch the editor first, produce the pitch in SUBMIT.md (under 150 words) and a draft only if the pack asks.
AI policies: if the outlet requires disclosure, write it in the required form (SUBMIT.md). If it bans or screens AI prose, use `outline-only`.
Cut order: examples, then background, then secondary sections.
